# Microrust
Microrust Application Framework

## Features
* Dependency Injection ala [Waiter DI](https://github.com/dmitryb-dev/waiter) and [Rocket - Request Guards](https://rocket.rs/v0.4/overview/)
* HTTP Routing ala [Rocket - Dynamic Params](https://rocket.rs/v0.4/overview/) and [Actix Web - Scoping Routes](https://actix.rs/docs/url-dispatch/)
